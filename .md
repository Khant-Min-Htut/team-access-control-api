# Team Access Control API — SaaS IAM

## Project Overview

Build a production-style Identity and Access Management (IAM) backend for a multi-tenant SaaS application.

The purpose of this project is to demonstrate strong backend engineering skills, including:

- Authentication
- Authorization
- Multi-tenancy
- RBAC
- Session management
- Audit logging
- PostgreSQL data modeling
- Redis caching and rate limiting
- Security
- Testing
- API documentation
- Clean and scalable architecture

The application should be built as a REST API.

# Important Development Rules

## 1. Build the project incrementally

DO NOT generate the entire application at once.

Build one module at a time.

After completing each phase:

1. Explain what was implemented.
2. Show the important files.
3. Explain how the code works.
4. Run/build/test the project.
5. Fix errors before moving to the next phase.

Wait for confirmation before starting the next major phase.

---

## 2. Beginner-friendly implementation

The developer is learning NestJS backend architecture.

Do not hide important logic behind complicated abstractions.

Prefer readable code such as:

```ts
@Injectable()
export class UsersService {
  constructor(
    @InjectRepository(User)
    private readonly usersRepository: Repository<User>,
  ) {}

  async findByEmail(email: string) {
    return this.usersRepository.findOne({
      where: { email },
    });
  }
}
